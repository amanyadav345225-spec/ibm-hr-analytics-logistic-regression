# IBM HR Analytics - Employee Attrition Prediction

## Project Overview

This project analyzes employee data and builds a Logistic Regression model
to predict employee attrition.

The main goal is to understand the factors associated with employee
attrition and use machine learning for prediction.

## Dataset

The dataset contains employee-related information such as:

- Age
- Monthly Income
- Job Role
- Job Satisfaction
- OverTime
- Years at Company
- Marital Status
- Education
- Attrition

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Categorical Feature Encoding
6. Train-Test Split
7. Logistic Regression
8. Model Evaluation

## Machine Learning Model

Logistic Regression is used because the target variable,
`Attrition`, is a binary classification problem.
